# Projet d'exemple

Un fichier **volontairement faux** (calc.py : la somme soustrait au lieu
d'additionner) et son test (check.py). C'est le support de la démo : Lumio
lance le test, affiche l'échec, propose la correction, puis revérifie.

## Essayer en deux minutes

1. Dans Lumio : **Parcourir** → choisis ce dossier exemple.
2. Ouvre *Réglages* (Ctrl+K) et mets la commande de vérification à :
   python check.py
3. Clique **Vérifier** : le test échoue, l'erreur s'affiche dans le chat.
4. Demande : « Le test check.py échoue. Corrige calc.py. »
5. Accepte le diff proposé : la vérification repasse au vert toute seule.

Rien n'est envoyé sur Internet si tu utilises un modèle local.
